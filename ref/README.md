# /ref — Darkcore & Sadcore Aesthetic References

This directory is designated for darkcore, sadcore, and webcore reference imagery, moodboards, and media assets for **CRUX_KYOMU.SYS**.

### Aesthetic Themes Present:
- **Visual Motif**: Gothic wire cruciforms (`†`), chromatic aberration, VHS grain & scanlines, desaturated monochrome with crimson blood and ghostly cyan accents.
- **Atmosphere**: Digital melancholia, Japanese void philosophy (虚無), fragmented memory buffers, decaying UI dialogs, eerie ambient soundscapes.
